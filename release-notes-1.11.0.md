Own FPS limiter and on-screen display, new Video Editor logo, snip, PDF and player fixes

## FPS limit and on-screen display (new, made by Utylix itself)
- **Limit to N FPS** now works without RivaTuner and without any extra download or administrator question for programs that run as you. A small part of Utylix is put into the program's graphics (Direct3D 9, 10, 11 and 12, 64-bit and 32-bit games) and holds it to the limit, exactly, per copy of the program.
- **Show FPS** (a box on each row in Memory limits): an on-screen display in the RivaTuner / MSI Afterburner look - orange values, coloured labels. Choose **FPS only** or the **Full display**: GPU, memory, CPU, RAM, graphics API and FPS. It follows the game window the moment you move it and hides when the game is not in front.
- The RivaTuner download and its buttons are gone.

## New Video Editor logo
- UtylixVid.exe, its window and its shortcuts use the new play-and-film logo.

## Fixes
- **Snip**: Win + S from another program no longer cancels itself; the mode bar at the top can be dragged out of the way (by its grip or edges); hold **Space** while dragging a selection to move it.
- **PDF editor**: files from a server that another program has open now open; PDFs with junk in front of the header or a broken index are repaired when possible; the error says the size and a code.
- **Video player**: the first video after the PC starts is quicker (the engine's files are prepared quietly in the background).
- **Memory limits**: one bordered card per program, a tidy "Running now" list, shorter text.
- **Dashboard**: the Quick actions tiles are all the same size; the RAM Lighting card is one short line.
- **Tray menu** is shorter.
- **About** is now "Utylix Pro": what each app does, and a Support me section (GCash).

Windows may ask for permission once if you allow the administrator guard (needed only for programs that run as administrator). Some anti-cheat programs do not like any program that puts code into a game; the limit and the display work only for the programs you list.
