Video editor, memory and CPU limits, FPS tools

## Utylix Vid Editor (new)
- A separate program, **UtylixVid.exe**, with its own settings (it never touches Utylix's settings).
- Premiere-style workspace: timeline with the zoom navigator, program and source monitors, Effect Controls, Effects, Info, History and Markers panels.
- Drag, scale and rotate pictures, videos and titles right on the monitor; keyframes; colour (Lumetri-style) controls.
- 51 transitions, placed between two clips and centred on the cut like Premiere; click one and press Delete to remove it.
- Export to MP4 (H.264 / H.265), WebM, GIF, MP3 and WAV.

## Free up memory (new)
- Right-click the desktop: **Free up memory** (in the middle group, next to Refresh). After one permission it runs silently with administrator rights.
- **Memory and CPU limits per program** (tray, Dashboard): give a program such as a game client a memory limit, a lower priority, efficiency mode or a CPU cap. For several clients of one game, choose which copies a row applies to (by window title, everything except your main account, or everything except the one in front).
- **FPS**: the window shows the frames per second of each copy. A row can also have a "Limit to N FPS": exact with RivaTuner, which you can download from the installer's extra parts page or the Memory limits window (it is downloaded from Guru3D's mirror, not bundled), otherwise a rough CPU cap.
