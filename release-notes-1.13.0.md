PDF editor: real tables, moving things like Nitro, and Word files that look like the PDF

- **Save as Word keeps the page looking the same.** Before, converting a PDF to .docx lost drawings, colours, table shading and backgrounds, pushed text under photos and turned 2 pages into 4. Now each page comes out as it is: the page without its text sits behind (colours, lines, diagrams, photos, logos) and every paragraph of text is a text frame placed where it stood, still real editable text with its font, size, bold, italic and colour. A font this PC doesn't have is swapped for a similar one so lines keep their width, and a "fi" the PDF stores without a letter code is written back as "fi". Pick **Text flows (easier to edit)** in the dialog for a normal Word document with real Word tables. Scans still use the flowing way.
- **Tables in the PDF editor.** Mark up > **Table** draws a real table: type in the cells, drag the lines, header row, striped rows, line styles, text size, **Align** (left / centre / right and top / middle / bottom), bold, fill colour, merge and split cells, add and delete rows and columns, and Ctrl+V pastes cells copied from Excel or Word. **Edit a table** reads a table that is already in the PDF into a real table you can change. Merged cells are chosen whole, and a cell can hold a **picture** (from a file, or pasted).
- **Moving, resizing and deleting things already in a PDF now works like Nitro / Acrobat.** The page's own drawing instructions are changed in place, so nothing else on the page is written again: soft shadows, gradients and colours stay. A line of text is picked whole (not letter by letter) and moves with its colour. When a change can't be done safely Utylix says so and offers a picture move instead.
- Menus of the PDF editor are tidier (submenus), and Table ▾ has an Align button.
